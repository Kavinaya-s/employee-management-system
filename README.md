# Employee Management System

This is an Employee Management System project that I am building to learn full stack development and backend concepts using Spring Boot.

## Technologies Used
- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- MySQL
- HTML
- CSS
- Bootstrap

## Features
- Add Employee
- View Employee List
- Update Employee Details
- Delete Employee
- Database Connectivity with MySQL

## Purpose of the Project
The main purpose of this project is to improve my understanding of:
- CRUD Operations
- Backend Development
- Database Integration
- Spring Boot Framework
- Git and GitHub
